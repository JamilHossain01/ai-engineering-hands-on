# ২ মাসের ইনটেনসিভ এআই ইঞ্জিনিয়ার রোডম্যাপ (ফুল-টাইম, দিনে ৭+ ঘণ্টা)
### ৮ মাসের প্ল্যান থেকে সংক্ষিপ্ত — গভীরতা একই, শুধু সময় কমানো হয়েছে

---

## এই সংক্ষিপ্তকরণ কেন কাজ করবে

দিনে ৭+ ঘণ্টা করে ৮ সপ্তাহে আপনি প্রায় **৩৯০ ঘণ্টা** পড়াশোনা/কাজ করবেন — যা মূল ৭-৮ মাসের প্ল্যানে দিনে ১.৫-২ ঘণ্টা করে করা মোট সময়ের প্রায় সমান। তাই গভীরতা কমছে না, শুধু ক্যালেন্ডার সময় কমছে। যা বদলাচ্ছে:

- আলাদা "protected cooldown" সপ্তাহ লাগবে না — প্রতিদিন যথেষ্ট সময় থাকায় থিওরি (Karpathy) আর অ্যাপ্লিকেশন কাজ (Donner/প্রজেক্ট) **একই দিনে** করা যাবে, নিচের ব্লক স্ট্রাকচার মেনে চললে context-switch fatigue হবে না।
- প্রতি ফেজে পোর্টফোলিও প্রজেক্ট কম রাখা হয়েছে (২-৩ এর বদলে ১টি ফ্ল্যাগশিপ) — কোয়ালিটি ও গভীরতা প্রাধান্য পাবে, ব্রেডথ কমবে।
- Phase 4 (MLOps) সবচেয়ে বেশি কমানো হয়েছে — এটা মূলত "existing pattern পড়ে অ্যাপ্লাই করা" ফেজ, অরিজিনাল-রিসার্চ-হেভি নয়।

**প্রতিদিনের স্ট্রাকচার (৭ ঘণ্টা), পুরো প্ল্যানে ব্যবহার হবে (আলাদা উল্লেখ না থাকলে):**
- **ব্লক ১ (২ ঘণ্টা, সকালে):** ভিডিও/রিডিং — Donner এর কোর্স বা Karpathy, সপ্তাহ অনুযায়ী
- **ব্লক ২ (৪ ঘণ্টা):** হ্যান্ডস-অন বিল্ডিং — কোড শুরু থেকে নিজে হাতে লেখা, নিজের প্রজেক্টে এক্সটেন্ড করা
- **ব্লক ৩ (১ ঘণ্টা, দিনের শেষে):** ডিবাগ ব্যাকলগ, GitHub commit + জার্নাল এন্ট্রি লেখা, পরের দিনের প্ল্যান

এটাকে কোর্স না ভেবে ফুল-টাইম জব হিসেবে ট্রিট করুন। উইকেন্ড: শনিবার পুরো একদিন বিল্ডিং, রবিবার হালকা রিফ্লেকশন/ক্যাচ-আপ (৩-৪ ঘণ্টা)।

## সপ্তাহ ধরে ধরে বিস্তারিত

### সপ্তাহ ১ — সেটআপ + অ্যাপ্লিকেশন-লেয়ার স্প্রিন্ট শুরু
**Phase 0 (শুধু Day 1) + Phase 1 শুরু**

- **Day 1:** পুরো এনভায়রনমেন্ট সেটআপ (uv, Ollama, MLX, GitHub repo, API keys)। মেন্টাল-মডেল ম্যাপিং এক্সারসাইজ (লিখে রাখুন)। Ed Donner এর কোর্স শুরু করুন।
- **Days 2–7:** Ed Donner এর কোর্স দ্রুত এগিয়ে নিন — LLM APIs, প্রম্পটিং প্যাটার্ন, RAG ফান্ডামেন্টালস, প্রোভাইডার অ্যাবস্ট্রাকশন। প্রতিটা মডিউল শেখার পর সেদিনই একটা ভ্যারিয়েশন দিয়ে রিবিল্ড করুন (অন্য vector DB, অন্য প্রোভাইডার) — শুধু ফলো করে গেলে হবে না।
- **উইকেন্ড প্রজেক্ট সিড:** **Provider-Agnostic LLM Gateway** (FastAPI, streaming, retries, structured outputs) শুরু করুন।

**এক্সিট চেক:** Donner এর কোর্সের ~৬০% শেষ, আর কাজ করা একটা gateway service রেডি।

---

### সপ্তাহ ২ — অ্যাপ্লিকেশন-লেয়ার স্প্রিন্ট শেষ + RAG/Agent প্রজেক্ট
- **Days 1–3:** Ed Donner এর কোর্স শেষ করুন (agentic workflows, multi-agent systems, tool calling)।
- **Days 4–7:** আপনার **Phase 1 ফ্ল্যাগশিপ প্রজেক্ট** বানান — একটা বেছে নিন:
  - On-device RAG assistant (SwiftUI + local vector search + Ollama), অথবা
  - Flutter agentic task app (FastAPI backend, tool-calling agent)

  আগে বেশি ডিফারেনশিয়েশন চাইলে on-device RAG নিন; দ্রুত iteration চাইলে Flutter agent নিন। দুটোই ঠিক আছে — সিদ্ধান্ত নিতে ৩০ মিনিটের বেশি সময় নেবেন না।

**এক্সিট চেক:** Donner এর কোর্স সম্পূর্ণ। GitHub-এ একটা deploy করা (লোকালি হলেও) RAG বা agent প্রজেক্ট, প্রপার README সহ।

---

### সপ্তাহ ৩ — Karpathy Overlap সপ্তাহ (micrograd + makemore)
**পুরো কম্প্রেসড প্ল্যানের সবচেয়ে গুরুত্বপূর্ণ সপ্তাহ — এটাকে প্রোটেক্ট করুন**

- **Days 1–3:** Karpathy এর micrograd ভিডিও। নিজের রিপোতে শুরু থেকে বিল্ড করুন, প্রতি লাইন নিজে টাইপ করে। আটকে না গেলে ওর কোড দেখবেন না।
- **Days 4–6:** makemore পার্ট ১-২ (bigram model → MLP)। একই নিয়ম: নিজে টাইপ করুন।
- **Day 7:** কনসোলিডেশন ডে — নতুন কিছু না। কাগজে, স্মৃতি থেকে, একটা ২-লেয়ার নেটওয়ার্কের ব্যাকপ্রপ ডিরাইভ করুন। না পারলে সময়সূচী নিয়ে চিন্তা না করে Day 1-3 এর মেটেরিয়াল আবার করুন। এই চেকপয়েন্টটা শিডিউলে থাকার চেয়ে বেশি গুরুত্বপূর্ণ।

ফুল-টাইম পেসেও এই সপ্তাহ আরও কম্প্রেস করবেন না, বা অ্যাপ্লিকেশন কাজ মেশাবেন না — এই ৮ সপ্তাহের মধ্যে এটাই ইচ্ছাকৃতভাবে একমাত্র pure-depth সপ্তাহ।

**এক্সিট চেক:** কম্পিউটেশনাল গ্রাফ কী এবং গ্র্যাডিয়েন্ট কীভাবে ব্যাকওয়ার্ড ফ্লো করে — এটা আপনি কোনো সাহায্য ছাড়াই ব্যাখ্যা করতে পারবেন।

---

### সপ্তাহ ৪ — GPT স্ক্র্যাচ থেকে + Tokenization
- **Days 1–5:** Karpathy এর "Let's build GPT" ভিডিও, পুরোটা। এটা ঘন — পুরো ৫ দিন বাজেট রাখুন, ধাপে ধাপে কোড নিজে টাইপ করুন (self-attention → multi-head → পুরো transformer block → training loop)।
- **Days 6–7:** Karpathy এর tokenization ভিডিও থেকে নিজের BPE tokenizer বানান।

**এক্সিট চেক:** স্ক্র্যাচ থেকে বানানো, কাজ করা (ছোট হলেও) একটা GPT ইমপ্লিমেন্টেশন আছে, আর নোট ছাড়াই attention এর Q/K/V matrix shapes ব্যাখ্যা করতে পারেন।

---

### সপ্তাহ ৫ — nanoGPT Training + Reintegration
- **Days 1–3:** nanoGPT ক্লোন করুন, MacBook Pro তে (MPS backend) ছোট একটা ডেটাসেটে ট্রেইন করুন (শুরুতে Shakespeare corpus ঠিক আছে)। ইচ্ছা করে ভেঙে দেখুন (LR বদলান, LayerNorm সরান) এবং কী হয় লগ করুন — সাকসেসফুল রান থেকে যতটা না, এখান থেকেই আসল ইনটুইশন তৈরি হয়।
- **Days 4–7:** **Reintegration স্প্রিন্ট** — সপ্তাহ ১-২ এর প্রজেক্টে (gateway বা RAG app) ফিরে যান এবং একটা ছোট লোকালি-ট্রেইন করা মডেল সোয়াপেবল provider হিসেবে যোগ করুন। এই এক্সারসাইজ API-লেভেল থিংকিং আর টেনসর-লেভেল থিংকিং একটা সিস্টেমে ফিউজ করে — Phase 3 তে যাওয়ার তাড়া থাকলেও এটা স্কিপ করবেন না।

**এক্সিট চেক:** ডকুমেন্টেড nanoGPT training run (loss curve + hyperparameter log), আর একটা প্রজেক্ট যেখানে cloud API আর নিজের ট্রেইন করা মডেল দুটোই আছে।

---

### সপ্তাহ ৬ — Fine-Tuning ও Quantization
**Phase 3 শুরু — ৮ সপ্তাহ থেকে ২ সপ্তাহে কম্প্রেসড**

- **Days 1–2:** Hugging Face `transformers`/`peft`/`trl` ফান্ডামেন্টালস — লাইব্রেরি API শেখা হিসেবে ট্রিট করুন, নতুন থিওরি না (Phase 2 এর ম্যাট্রিক্স কাজ থেকে LoRA এর math আপনার ইতিমধ্যে বোঝা)।
- **Days 3–4:** LoRA/QLoRA fine-tuning — একটা ছোট ওপেন মডেল (Qwen2.5-0.5B/1.5B বা Llama 3.2 1B/3B) নিজের কিউরেট করা ডোমেইন ডেটাসেটে (যেমন নিজের Stack Overflow উত্তর, বা Flutter/Swift docs Q&A) রিয়েল fine-tune করুন।
- **Days 5–7:** Quantization + Apple Silicon-এ MLX fine-tuning। Core ML conversion শুরু করুন।

**এক্সিট চেক:** ডকুমেন্টেড before/after example সহ একটা fine-tuned মডেল।

---

### সপ্তাহ ৭ — On-Device Deployment (ফ্ল্যাগশিপ প্রজেক্ট)
- **Days 1–4:** Core ML conversion (বা MLX deployment) শেষ করুন এবং fine-tuned মডেলটা একটা রিয়েল SwiftUI অ্যাপের মধ্যে শিপ করুন। এটাই আপনার **ক্যাপস্টোন ফ্ল্যাগশিপ** — fine-tune → quantize → deploy-on-device পাইপলাইন। এখানে এক্সট্রা সময় বাজেট রাখুন; Core ML conversion এর quirk-এ একদিন লস হওয়ার সম্ভাবনা সবচেয়ে বেশি।
- **Days 5–6:** এই মডেলের জন্য একটা ছোট eval harness বানান (golden Q&A set, automated scoring, before/after comparison) — এটাই আপনার Phase 4 evaluation কাজ হিসেবেও কাজ করবে।
- **Day 7:** এই প্রজেক্টের টেকনিক্যাল README/ব্লগ পোস্ট লিখুন — এটাকে আপনার প্রাইমারি ইন্টারভিউ আর্টিফ্যাক্ট হিসেবে ট্রিট করুন।

**এক্সিট চেক:** ডিভাইসে চলা একটা fine-tuned, quantized মডেল রিয়েল অ্যাপে, লিখিত eval report সহ।

---

### সপ্তাহ ৮ — MLOps Essentials + পোর্টফোলিও পলিশ
**Phase 4, শুধু কোর এসেনশিয়ালস + ক্যাপস্টোন wrap-up**

- **Days 1–2:** Observability/tracing বেসিকস (সপ্তাহ ১-২ এর gateway প্রজেক্টে tracing + cost logging যোগ করুন)। Chip Huyen এর production LLM মেটেরিয়াল পড়ুন কনসেপচুয়াল ফ্রেমিং এর জন্য (স্কিম করুন, ডিপ-রিড না — আপনার ব্যাকএন্ড অভিজ্ঞতা থেকে প্র্যাকটিশনার ইনটুইশন ইতিমধ্যে আছে)।
- **Day 3:** একটা AI system design write-up (একটা বাস্তব প্রোডাক্ট বেছে নিন, যেমন "১ মিলিয়ন ইউজারের জন্য customer support agent ডিজাইন করুন" — এটা ADR লেখার মতো করে লিখুন)।
- **Days 4–5:** পোর্টফোলিও পলিশ — সব রিপোর জুড়ে README ক্লিন করুন, প্রতিটা প্রজেক্টে নিশ্চিত করুন: এটা কী করে, কেন এভাবে আর্কিটেক্ট করা হয়েছে, বেশি সময় থাকলে কী বদলাতেন।
- **Days 6–7:** সপ্তাহ ৭ এর টেকনিক্যাল ব্লগ পোস্ট পাবলিশ করুন, GitHub প্রোফাইল ফাইনালাইজ করুন, এবং (জব খুঁজলে) রেজিউমে/পোর্টফোলিও ন্যারেটিভ on-device fine-tuning ফ্ল্যাগশিপ প্রজেক্টকে হেডলাইন স্টোরি হিসেবে রেখে সাজানো শুরু করুন।

**এক্সিট চেক:** GitHub-এ ৩-৪টা পলিশড, ডকুমেন্টেড রিপো, একটা পাবলিশড টেকনিক্যাল রাইট-আপ, একটা সিস্টেম ডিজাইন ডক, আর ইন্টারভিউয়ের জন্য একটা স্পষ্ট হেডলাইন স্টোরি।

```
সপ্তাহ ৮   Observability + system design + পোর্টফোলিও পলিশ + পাবলিশ
```

## ৮ মাসের ভার্সনের তুলনায় কী বাদ পড়েছে
কম্প্রেশনের ট্রেডঅফ সম্পর্কে সরাসরি বলছি:
- **কম পোর্টফোলিও প্রজেক্ট** (প্রতি ফেজে ২-৩ এর বদলে ১টা ফ্ল্যাগশিপ) — গভীরতা বজায় আছে, ব্রেডথ কমেছে।
- **Phase 4 (MLOps) পাতলা** — কাজ করা observability আর একটা system design doc থাকবে, কিন্তু ফুল প্ল্যানের গভীর serving-infrastructure এক্সপ্লোরেশন (vLLM/TGI, autoscaling) থাকবে না। জব খোঁজার সময় বা জবে থাকা অবস্থায় এটাকে "Phase 5 backlog" হিসেবে ট্রিট করুন।
- **আলাদা specialization ফেজ নেই** — on-device ফ্ল্যাগশিপ প্রজেক্টটাই ডিফল্টভাবে আপনার specialization signal (on-device/edge AI), যা আপনার ব্যাকগ্রাউন্ডের সাথে ভালোভাবে মানানসই, কিন্তু ৮ মাসের প্ল্যানের মতো agentic-systems বা platform-engineering specialization ততটা গভীরে এক্সপ্লোর করা হবে না।
- **কোনো কিছু ভুল হলে কম বাফার।** প্রায় কোনো স্ল্যাক ডে ছাড়া ফুল-টাইম ডেইলি এক্সিকিউশনে একটা খারাপ ডিবাগিং ডে (বিশেষত সপ্তাহ ৭ এর Core ML conversion) পরের দিনের প্ল্যানে ঢুকে পড়তে পারে। ধরে নিন সপ্তাহ ৭ হয়তো ১-২ দিন সপ্তাহ ৮ এর পলিশ টাইমে ছড়িয়ে যেতে পারে — সেটা ঠিক আছে, system design doc আগে ফ্লেক্স করবে।
